# Quizzler App | Python

A GUI-based True/False Quiz Application developed using Python and Tkinter. The application fetches quiz questions from the Open Trivia Database API and allows users to answer questions through an interactive interface.

### Features
- Fetches quiz questions using the Open Trivia Database API.
- Interactive True/False answer buttons.
- Displays instant feedback with color changes for correct and incorrect answers.
- Tracks the user's score throughout the quiz.
- Displays the final score after completing all questions.

### Technologies Used
- Python
- Tkinter (GUI)
- Requests (API integration)
- JSON
- HTML module

### Concepts Practiced
Object-Oriented Programming (OOP), API requests, JSON data handling, GUI development, exception handling, and Python modules.
